# 推广视频

两版，**用 v2**。

| 文件 | 状态 |
|---|---|
| `veilbound-promo-v2.mp4` | ✅ **当前版本**，35s / 1080×1920 / 30fps / 含音轨 |
| `veilbound-promo.mp4` | ⚠️ 已废弃，纯文字排版、无声、剧透真相 |
| `make_promo_v2.py` | v2 生成脚本 |
| `make_promo.py` | v1 脚本，仅作存档 |

## v1 错在哪（记下来免得再犯）

1. **没有人物** —— 纯文字排版，是 PPT 不是游戏广告
2. **把真相全剧透了** —— 37 分钟、姐姐、守夜人全说了，观众没有想玩的理由
3. **没有音乐** —— 把该做的活推给了用户

## v2 的做法

**展示游戏长什么样，而不是讲剧情讲什么。**

核心是三格画面，都是这个游戏独有的：

| 秒 | 内容 |
|---|---|
| 0–3.6 | 雨夜，一个人倒在山道边（剪影 + 路灯 + 雨） |
| 3.6–8.4 | **分屏**：「你看到的」vs「他看到的」——同一个人，不是同一件事 |
| 8.4–14 | **游戏 UI**：三个选项，「做什么你定，但判定不由 AI 定」 |
| 14–19.2 | **判定明账**：掷骰 17 / DC 15 / 加值 +1 → 成功 |
| 19.2–24.6 | **表演与内心**：「我可以带你出山」vs「等他伤好就抢他」 |
| 24.6–29.9 | **揭面**：两个人正面相对 |
| 29.9–35 | 「你分不清，谁在骗你」+ 标题 |

**不剧透任何真相。** 只给氛围和机制。

## 技术

- 画面：Pillow 逐帧绘制（1080×1920 / 30fps / 1050 帧）
- 人物：代码画的剪影，站在光晕前形成轮廓
- 音乐：numpy 合成——雨声（带通白噪声）+ 低频 drone（55/82.5/110Hz）+ 心跳（47Hz 脉冲）+ 转折点撞击
- 编码：ffmpeg（H.264 + AAC）

不用任何视频大模型或音源文件。


场景在 `SCENES` 列表里，每个场景一个函数；文案在 `text_blocks` 调用处。

## 已知局限（诚实版）

- **人物是极简剪影**，不是美术资源。能认出是人，但谈不上好看。
- **音乐是算法合成的氛围音**，不是作曲。听得出雨和压迫感，但别指望旋律。
- **没有配音**。需要旁白的话得自己录或用剪映 AI 配音。
- 没有 3D / 实拍。VRM 角色演出是 [../docs/3d-avatar.md](../docs/3d-avatar.md) 里 P1 之后的事。

**这是"能用"级别，不是"精品"级别。** 想上投放，建议找美术换掉剪影、找作曲换掉音轨。
